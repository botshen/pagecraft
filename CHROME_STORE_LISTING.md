## 3. Chrome Web Store Privacy & Permission Justifications (审核后台填写项)

- **Official Website**: `https://pagecraft.shenxin.space`
- **Privacy Policy URL**: `https://pagecraft.shenxin.space/privacy`
- **Developer Contact / Support Email**: `botzgbj@gmail.com`
- **Single Purpose Description**:
  > User-directed webpage layout customizer and MV3 userscript manager: PageCraft allows users to customize the appearance and functionality of websites they choose using local CSS rules and isolated JavaScript userscripts authored or enabled via the Side Panel.
- **`sidePanel`**:
  > Displays the persistent PageCraft customization studio next to the active webpage while the user selects page elements, previews CSS changes, and manages saved rules.
- **`storage`**:
  > Persists the user's saved CSS customizations, userscripts, UI preferences, and optional BYOK API settings locally in `chrome.storage.local`.
- **`tabs`**:
  > Reads the active tab URL to scope newly generated `@match` patterns to the current site and listens for tab/SPA URL updates (`tabs.onUpdated`) strictly to apply or remove matching user-enabled CSS rules.
- **`scripting` + `host_permissions (<all_urls>)`**:
  > Persistent user-saved CSS/JS rules must apply automatically on any user-chosen website upon page load without clicking the toolbar icon (`activeTab` expires on navigation). Also injects the on-demand visual Element Picker and selector hit check strictly when initiated by the user. Zero background tracking scripts are injected.
- **`userScripts`**:
  > Registers and executes user-enabled JavaScript userscripts strictly inside Chrome's official MV3 `chrome.userScripts` isolated `USER_SCRIPT` world (`csp: "script-src 'self'", messaging: false`), gated behind the browser's per-extension "Allow User Scripts" toggle.
- **Remote Code**:
  > **No** remote code is fetched or executed. PageCraft uses the official MV3 `chrome.userScripts` API (`USER_SCRIPT` world with `csp: "script-src 'self'", messaging: false`), never downloads or evaluates remote `@require` scripts or remote configuration code, bundles all 10 built-in recipes statically at build time, and stores all user rules locally in `chrome.storage.local`.
- **Data Usage Disclosure (`Website Content` Checkbox)**:
  > Check **Website Content** ONLY, and leave all other personal/history/activity boxes unchecked. Disclosure note: *"Only when the user explicitly clicks Generate or Refine in Free Cloud Trial mode, PageCraft transmits the user's text instruction, sanitized host/path hint, client-side redacted page title, structural page landmarks, and picked element structural DOM snippet to synthesize the requested CSS/JS rule. Emails, API tokens (`sk-...` / `Bearer`), long numeric IDs, URL query parameters, and password fields are scrubbed client-side prior to transmission, and prompts are never stored in our database."*
