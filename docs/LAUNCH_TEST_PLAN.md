# 上架前实测计划：10 个真实网站生成成功率

**目的**：上架前确认 AI 生成的改造真的能用。**成功率低于 60% 不上架**，先去修 prompt 和选择器校准逻辑。

## 准备
1. 设置云端 Key：浏览器打开 `https://pagecraft.shenxin.space/admin`（凭 `ADMIN_TOKEN` 登录）在线配置 DeepSeek API Key 并点击"测试连接"确认连通性与余额（或执行 `cd workers/cloud && npx wrangler secret put PRIMARY_LLM_API_KEY`）；若仅测本地逻辑，也可在扩展设置页填自己的 DeepSeek Key（BYOK），不消耗免费额度。
2. `pnpm build`，然后在 `chrome://extensions` 打开开发者模式，"加载已解压的扩展程序"，选择 `.output/chrome-mv3`。
3. 在扩展详情页打开 **允许用户脚本**（JS 用例需要）。

## 判定标准
- ✅ **一次成功**：首次生成，点"启用并保存"后效果符合预期
- 🟡 **微调成功**：经过 ≤ 2 轮微调或"自动校准选择器"后符合预期
- ❌ **失败**：2 轮后仍不符合预期、报错，或者页面被改坏
- 每个用例都点一下 👍/👎，顺便验证反馈链路，事后在 `https://pagecraft.shenxin.space/admin` 管理后台或用 `pnpm stats 1` 核对计数
- **刷新页面后再看一次**，确认改造能持久生效

**成功率** = (✅ + 🟡) / 10。另外单独记录 ✅ 率，它反映首次体验。

## 失败用例怎么修
- 选择器 0 命中：看 `lib/picker/selector.ts` 是否选中了哈希类名，以及 prompt 里的 DOM 骨架是否足够
- 生成的 JS 在 SPA 里只生效一次：检查 prompt 是否要求使用 `MutationObserver`
- 返回的 JSON 解析失败：看 `parseGeneratedMod` 和 `extractJsonString`
