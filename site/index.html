PageCraft 有后台服务器或收集浏览记录吗？ Does PageCraft operate any backend servers?

完全没有。PageCraft 零遥测、零统计、零官方中转服务器；请求仅直连浏览器内置 Gemini Nano、本机 Ollama 或你自己配置的模型接口，且发送前在本地自动脱敏。 No. PageCraft runs zero telemetry, analytics, or proxy servers. Prompts go straight to Gemini Nano, local Ollama, or the endpoint you choose.

没有云端 API Key 也能直接使用吗？ Can I customize pages without an API key?

可以。点选任意广告/元素直接隐藏、内置热门网站净化与表格导出配方、CSS 排版滑块，以及 Chrome 内置 Gemini Nano、本机 Ollama 和 pagecraft-mcp 均无需任何云端 API Key。 Yes. Direct element hiding, built-in recipes, CSS sliders, Chrome Gemini Nano, local Ollama, and pagecraft-mcp all work with zero cloud API keys.

JavaScript 改造脚本是如何安全隔离的？ How does PageCraft sandbox JavaScript mods?

纯样式规则通过原生 insertCSS 免开关即时注入；交互脚本运行在浏览器官方隔离的 MV3 chrome.userScripts 世界中，未在扩展详情页开启「允许用户脚本」前绝不执行。 Scripts execute inside Chrome's official MV3 chrome.userScripts world and stay disabled until you turn on Chrome's Allow User Scripts toggle.

网页前端改版导致旧规则失效怎么办？ What happens when a webpage updates its DOM?

闭环自动自愈（Auto-Heal）会自动检测 0 命中的失效选择器，结合最新实时 DOM 结构与可选局部截图生成并验证新选择器。 Auto-Heal spots zero-match selectors, checks the live DOM and optional Vision tab capture, and proposes a verified selector replacement.
