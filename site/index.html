FAQ

常见问题解答Frequently Asked Questions

PageCraft 有任何后台服务器、账号注册或数据上报吗？Does PageCraft have any backend servers, user accounts, or telemetry?

完全没有。PageCraft 100% 运行在你的浏览器本地客户端：零官方服务器、零账号系统、零遥测或反馈打点。你的所有规则与自定义 API Key 均保存在本地 chrome.storage.local 中。None at all. PageCraft operates 100% client-side with zero PageCraft servers, zero accounts, and zero telemetry or feedback pings. All mods and settings live in your local chrome.storage.local.

不想配 API Key 能直接用吗？Can I use PageCraft without configuring a paid API key?

可以！内置 10 款高频配方与 /playground/ 练习靶场安装即用；此外你还可以直接开启 Chrome 内置端侧模型（Gemini Nano）或本机免费的 Ollama / LM Studio，甚至用你已订阅的 Claude Code / Cursor 通过 pagecraft-mcp 直接操控网页。Yes! All 10 built-in recipes and the /playground/ sandbox work instantly with zero setup. For AI generation, you can use Chrome Built-in AI (Gemini Nano) on-device, free local Ollama / LM Studio, or your existing Claude Code / Cursor subscription via pagecraft-mcp.

为什么纯 CSS 样式改造免开任何开关就能 0.1 秒生效？Why do visual CSS mods work in 0.1s with zero developer toggles?

PageCraft 采用双引擎最小权限设计：隐藏干扰模块、宽屏护眼等视觉规则通过原生 chrome.scripting.insertCSS 注入，无需额外权限开关即可实时生效与关闭还原；仅当需要挂载交互按钮（如导出 CSV）时才启用隔离的 chrome.userScripts 沙箱。PageCraft separates styling from scripting: visual tweaks run via native chrome.scripting.insertCSS in 0.1s with zero browser toggles, while interactive DOM scripts run inside Chrome's isolated MV3 chrome.userScripts sandbox.
