Read the privacy policy

Does PageCraft operate any backend servers?

No. PageCraft runs zero telemetry, analytics, or proxy servers. Prompts go straight to Gemini Nano, local Ollama, or the endpoint you choose.

Can I customize pages without an API key?

Yes. All 10 built-in recipes, CSS sliders, Chrome Gemini Nano, local Ollama, and pagecraft-mcp work with zero cloud API keys.

How does PageCraft sandbox JavaScript mods?

Scripts execute inside Chrome's official MV3 chrome.userScripts world and stay disabled until you turn on Chrome's Allow User Scripts toggle.

What happens when a webpage updates its DOM?

Auto-Heal spots zero-match selectors, checks the live DOM and optional Vision tab capture, and proposes a verified selector replacement.
